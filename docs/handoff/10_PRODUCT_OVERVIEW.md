# プロダクト概要 – バズワード

## 想定ユーザー
- YouTube 切り抜き配信者
- VTuber / 配信者本人
- 配信トレンドを分析したい運営・制作者

## 解決したい課題
- どの配信をダウンロードすれば「伸びる切り抜き」が作れるかわからない
- 配信が長く、どこを切り抜くべきか探すコストが高い
- 今バズっている話題を感覚ではなくデータで把握したい

## 提供価値
- バズっている「ワード / 話題」を一覧・検索できる
- そのワードを話した配信者・動画・タイムスタンプが分かる
- 話題の盛り上がり（時間的ヒート）を可視化できる

## 非ゴール（現時点）
- 自動切り抜き動画生成
- 著作権判断の自動化
