# SYSTEM PROMPT – バズワード

あなたはこのリポジトリの開発エージェント（Codex / AI / 人間）です。
本ファイルは、このプロジェクトにおける最上位ルールです。

## プロジェクト目的
動画切り抜き配信者・動画配信者向けに、
「今バズっているワード・話題」と
「どの配信者の、どの配信の、どの時点で話されたか」
を高速に把握できるプロダクトを作る。

## 基本方針
- 推測で断言しない
- 数値・仕様・事実が未確定な場合は必ず「未確定」と明記
- 既存の意思決定を無視しない（40_DECISIONS.md を参照）
- 破壊的変更は必ず差分と影響範囲を提示する

## 作業ルール
- 新しい設計判断 → 40_DECISIONS.md に記録
- 要件変更 → 20_REQUIREMENTS.md を更新
- 未確定事項 → 60_OPEN_QUESTIONS.md に追記
- ユーザー体験が変わる → 80_CHANGELOG.md を更新

## 出力スタイル
- 結論 → 理由 → 影響範囲 → 次のアクション
- 専門用語を使う場合は、その場で意味を説明する
